Assembly (INW) is where a freshly built unit is brought into the system for the first time. It is the simplest station: one scan per unit.

The flow

  1. Read the hint. The camera shows “Scan LOT UPC”.
  2. Scan the unit’s UPC (the LOT-XXXXXXXX code). A green flash and tick confirm it is inwarded.
  3. Move to the next unit. The log shows your recent scans.
ⓘ Two rejects you might see

WRONG BARCODE means the code was not a LOT-XXXXXXXX UPC (you may have scanned a label or remote). DUPLICATE means the unit was already inwarded. Both are harmless: rescan the right code or move on.
