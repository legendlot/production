Store Issue is where the store picks component bags against a production run before issuing it. You select the run, then scan the bag QRs as you pick them, and a progress bar tracks how much of the run is done.

The flow

  1. Select the run from the dropdown (runs already being picked show “Picking”). A progress bar appears: “X/Y parts picked”.
  2. Scan each bag QR as you pick it. A green tick logs the part and updates the progress.
  3. Finish. When every part is done you see “All parts picked, [run] ready to issue”.
⚠ Over-picking is allowed but flagged

If you scan more of a part than the run needs, it is still counted (so nothing is lost), but you get an orange OVER PICK warning so a supervisor can check it. You must select a run before scanning (else “No run selected”), and only bag QRs are accepted (else “Scan a bag QR”).
