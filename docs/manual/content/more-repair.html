The Repair station tracks units through a structured repair run: starting a repair, then passing or scrapping the unit. You set the mode, pick the run, and scan.

The flow

  1. Pick a mode: Start (begin repairing), Pass (repaired), or Scrap (cannot fix). Start also needs a repair run chosen from the dropdown.
  2. Scan the unit’s LOT UPC. The hint changes with the mode (“Scan unit to start repair”, “Scan repaired unit”, “Scan unit to scrap”).
  3. See the confirmation: “In Repair”, “Repaired”, or “Scrapped”.
ⓘ Mode first, run for Start

If you scan without choosing a mode you get “Select mode”; if you choose Start without a run you get “Select run”. The repair runs themselves are created by the team in Garage; this station just records each unit’s progress through one.
