Lookup is a read-only tool: scan any code to see what it is, its status and history, without changing anything. It is the safe station for “what is this unit?” and for reprinting a lost label.

The flow

Scan any unit UPC, box label or remote. A result card shows the current status, the product, whether it is a car or remote, its paired partner, and the last several scans (with who, which line and when). You can also reprint the package or box label: pick a printer (L1 to L3 or D1 / D2) and tap Reprint. Scan Again clears it for the next lookup.

ⓘ Nothing here changes a unit

Lookup never writes a scan, so it is safe to use any time to check a unit or trace a problem. It is a deviceless utility, so it does not need station/line setup.
