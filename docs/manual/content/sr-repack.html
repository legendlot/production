Repack moves units from one sales channel to another (for example Retail to Ecom). Two stations work as a pair: Repack In frees the units from their old box, and Repack Out re-packs them to the new channel with a fresh label. Both pick a repack run first.

Repack In

Select the repack run, then scan the old box label (a BOX-XXXXX, or the unit’s existing batch label). The system frees every in-scope unit in that box and tells you how many: “N units freed, now scan at Repack Out”.

Repack Out

This works exactly like Packaging: pick the destination channel (Ecom or Retail), scan the car (then the remote if prompted), and a new label prints. Progress shows “repacked / target”, and “[run] complete” when the run is done. From here the unit re-enters the normal dispatch flow.

ⓘ Run first, then scan

Both stations need a repack run selected before scanning (else “No run selected”). Repack In takes the old box label; Repack Out takes the car UPC and behaves just like PKG, so the same “car first, channel set before scanning” rules apply.
