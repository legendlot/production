Device Setup binds one physical device to one station and one line for the shift. A supervisor normally does this after signing in with the PIN. Setup lasts until 1 AM, when the device locks and needs setting up again for the next shift.

What it’s for
Pointing a device at a station + line.
Who
Supervisor (+ Operator for dispatch sign-in)
Expires
1 AM each day.
Change later
The ⚙ button returns here.

Setting up a device

  1. Pick the station. Tap one station (tap again to deselect). Stations are grouped: Production, Dispatch, Store, External Runs, Legacy and Utilities.
  2. Pick the line. Production stations ask for a line (L1 to L5); dispatch stations ask for D1 or D2; shared stations (Lookup, Attendance, PKG Out, Returns Intake) need no line.
  3. Set the options. Choose the camera (back or front), whether the torch comes on while scanning, and the beep volume.
  4. Launch Scanner. The device finds its station record and opens the scan screen.

Dispatch stations: operators sign in too

The four dispatch stations (Pack, Dispatch In, Allocate, Dispatch Out) add one step: after the supervisor sets the device up, each operator scans their own QR ID card at the start of their shift before they can scan units (or types their ID with “Type ID instead”). The Change Op button in the top bar hands the device to the next person without redoing the whole setup.

⚠ “No active device found”

If setup says no active device exists for that station and line, that station/line has no registered device: pick the correct line, or ask an admin to register the device. Both the supervisor setup and the dispatch operator sign-in expire at 1 AM, so the first task each morning is to set the device up again.
