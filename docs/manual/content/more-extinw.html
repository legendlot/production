Outsourced Inward (EXT_INW) brings in units that were built by an outside vendor rather than on the line. It works just like Assembly, but routes the units to their outsourced run.

The flow

Scan each vendor unit’s LOT UPC (the hint reads “Scan LOT UPC, outsourced vendor unit”). A green tick confirms it is inwarded against the outsourced run. From there the unit flows through QC and packing like any other.

ⓘ Use this only for outsourced runs

This is the receiving point for vendor-made units, kept separate from the line’s own Assembly station so outsourced production is tracked on its own run. A non-LOT code gives “WRONG BARCODE”.
